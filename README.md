# MC-Petarh Event-Decor mock

Open `index.html` for the main site, or `Landing.html` directly. The index forwards to the landing page, whose links lead to the event inquiry pages, `Showroom.html`, and the privacy and terms templates.

The inquiry pages submit through Web3Forms using the configured access key.

`Showroom.html` currently uses the two portfolio images available in this folder. Add real, licensed event photos and descriptive alt text before expanding the gallery.
