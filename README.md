# 🎉 MC PETARH – Event Decoration & Planning

**Creating unforgettable moments, one celebration at a time.**

Welcome to **MC PETARH**, a Nigerian event decoration platform dedicated to transforming ordinary spaces into extraordinary experiences.

From intimate birthday celebrations to elegant weddings, traditional ceremonies, anniversaries, and corporate events, we bring creativity, style, and excellence to every occasion.

## 🌟 About the Project

MC PETARH is a modern event decoration website designed to showcase creative decoration services, display event inspiration, and make booking decorations easier for clients across Nigeria.

Our goal is to help people celebrate life's special moments with beautiful designs and memorable experiences.

## ✨ Features

- 🏠 **Beautiful Landing Page** – A welcoming introduction to our brand and services.
- 🎨 **Event Gallery** – Explore our decoration styles and previous event inspirations.
- 💍 **Wedding Decorations** – Elegant setups for traditional and white weddings.
- 🎂 **Birthday Decorations** – Creative themes for unforgettable birthday celebrations.
- 💑 **Couple & Anniversary Packages** – Beautiful romantic decoration concepts.
- 📅 **Online Booking** – A convenient way to request event decoration services.
- 📱 **WhatsApp Integration** – Contact us directly for enquiries and bookings.
- 📱 **Responsive Design** – Accessible on mobile phones, tablets, and desktops.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Odune360/MC-PETARH.git
   ```

2. Navigate into the project folder:

   ```bash
   cd MC-PETARH
   ```

3. Open `index.html` in your browser or use the Live Server extension in VS Code.
